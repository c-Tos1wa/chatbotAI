# Projeto: Chatbot com IA Generativa

## Objetivo

Criar um chatbot básico conectado a uma IA Generativa com possibilidade de torná-lo específico para uma empresa.

## Pré-requisitos

```
python 3
poetry 
pyenv
vscode
```

## Como iniciar este projeto

- No terminal, clonar este projeto:

```
git clone git@github.com:c-Tos1wa/chatbotAI.git
```

- Dentro da pasta criada:

```
code .
```

- NO VSCode, configurar virtualens e depois

```
poetry install
```

- Para ativar o ambiente, selecione o Python Interpreter na Paleta de Comandos

## Bibliotecas utilizadas

- [OpenAI](https://developers.openai.com/api/reference/python)
- [Streamlit](https://streamlit.io/)

obs: Também foi utilizado o plugin poetry-plugin-dotenv
